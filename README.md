# رزرو ساندویچ بوفه کارآفرینان و پویندگان

Node.js (Express) + SQLite (better-sqlite3).

## اجرا
    npm install
    npm start        # http://localhost:3000

متغیرهای اختیاری: PORT، DB_PATH، TRUST_PROXY=1 (پشت Nginx/Cloudflare).
دیتابیس به‌صورت خودکار در data/buffet.db ساخته می‌شود. برای تصویر واقعی ساندویچ، فایل public/img/hero.jpg را بگذارید.

## نکات فنی
- ظرفیت روزانه (۲۰) در جدول day_capacity برای هر تاریخ جدا ذخیره می‌شود؛ تغییر روز بر اساس ساعت Asia/Tehran خودکار است.
- ثبت رزرو در یک تراکنش IMMEDIATE (بررسی ظرفیت + تکراری بودن + درج) انجام می‌شود.
- تاریخ رزرو را فقط سرور تعیین می‌کند؛ بازه 07:30 تا 13:40 در سرور هم بررسی می‌شود.
